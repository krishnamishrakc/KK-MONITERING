FOCUS GUARD

Protect a study session

Block selected apps and enforce daily limits while Focus Guard is active. You can always end the session or use an emergency pass.

OFF
Optional Accessibility Service disclosure

When enabled, Android's Accessibility Service checks only the foreground app package name so your selected block list and usage limits can work. It does not inspect screen text, notifications, messages or typed content. You can turn it off at any time in Android Settings.

Limits apply while Focus Guard is active. Focus Guard remains optional; an Emergency Exit is always available from the blocking screen.
